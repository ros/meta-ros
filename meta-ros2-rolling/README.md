# meta-ros2-rolling

The ROS 2 **Rolling Ridley** distro layer — ROS 2's continuously-updated
development distro, tracking upstream more closely (and less stably) than the
named LTS/non-LTS releases. Recipes generated by
[superflore](https://github.com/ros-infrastructure/superflore) live under
`generated-recipes/`; local fixes are `.bbappend` files under
`recipes-bbappends/`.

See the [top-level README](../README.md) for how this fits into the overall
layer stack, and [`docs/recipe-overrides.md`](../docs/recipe-overrides.md) for
how to fix a generated recipe.

## Dependencies

- `core` (openembedded-core)
- `meta-python` (meta-openembedded)
- `openembedded-layer` (meta-openembedded)
- `ros-common-layer` (`meta-ros-common`)
- `ros2-layer` (`meta-ros2`)

Some packages in this layer are only built if an optional layer is also
present — see [README.md § Optional / Dynamic Layers](../README.md#optional--dynamic-layers).

## Compatibility

`LAYERSERIES_COMPAT_ros2-rolling-layer` is scoped per branch — this branch
declares `wrynose`. Each Yocto-release branch of this repo (`master`,
`wrynose`, `scarthgap`, ...) sets this to its own release only; see
[`AGENTS.md` § Branch model](../AGENTS.md#branch-model).
